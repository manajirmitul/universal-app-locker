Universal App Locker v1.0

ফিচার:
- প্রতিটি অ্যাপের জন্য আলাদা দৈনিক সময়সীমা (মিনিটে)
- সীমা শেষ হলে লক স্ক্রিন + PIN প্যাড
- PIN দিলে +৫ / +১৫ / +৩০ মিনিট অথবা আজকের জন্য সম্পূর্ণ আনলক
- অ্যাপ নিজেও PIN দিয়ে সুরক্ষিত (সীমা বদলাতে PIN লাগে)
- PIN হ্যাশ করে রাখা হয়; ৫ বার ভুলে ৩০ সেকেন্ড ব্লক
- প্রতি সেকেন্ডে নির্ভুল সময় গণনা; স্ক্রিন বন্ধ থাকলে গণনা হয় না
- কিবোর্ড/নোটিফিকেশন শেড খুললে গণনা থামে না
- Usage Access দিলে আজকের আগের ব্যবহারও ধরা হয়
- অ্যাপ খোঁজা, ডার্ক UI, আইকন

প্রথমবার সেটআপ:
1. অ্যাপ খুলুন, "Accessibility" চালু করুন।
   চালু না হলে: অ্যাপ ইনফো → ⋮ → Restricted settings অনুমতি দিন।
2. PIN সেট করুন।
3. ব্যাটারি "সীমাহীন" করুন (Oppo/Xiaomi এ জরুরি)।
4. যেকোনো অ্যাপে ট্যাপ করে সময়সীমা ঠিক করুন।

সীমাবদ্ধতা:
- Accessibility বন্ধ করলে বা অ্যাপ ডেটা মুছলে লক কাজ করবে না (Android এ পুরো bypass-proof করা যায় না)।
